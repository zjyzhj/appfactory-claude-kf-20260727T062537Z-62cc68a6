# Non-goals · TourWise v0

## 明确不做(v0)
1. 房源搜索、listing 聚合、地图找房、约看调度(portal 战场;network moat,本地零账号 v0 不可存活)。
2. 账号体系、登录、云同步、多设备、多人实时协作。
3. 任何形式的 AI:AI 打分、AI 备注总结、AI 推荐、聊天式助手(remote_ai: no)。
4. 房东/物业/中介巡检或 CRM 视角( RentCheck 的市场)。
5. 搬家执行管理：搬家公司比价、utilities 迁移、打包清单(v1+ 候选,见 features.md 迭代跑道)。
6. 房贷/ affordability 计算器(独立工具品类,会稀释决策楔子;v1+ 候选)。
7. 通用 checklist 模板市场(防止塌缩成 Checklist 换皮)。
8. 社交分享信息流、公开评价、社区内容。
9. iPad 专属布局、macOS、Android(v0 iPhone only;小屏 320×568 可用)。
10. 订阅、买断解锁、Premium 功能墙(商业化只允许 consumable Export Credit)。

## 不与 Top-N 竞争的面(镜像自 product.md §市场供给与立场)
- 不碰房源发现与约看(HotpPads 345957475 / Zumper 678683201)。
- 不碰房东巡检(RentCheck 1134017691)。
- 必须自营(缺失即塌缩为 0 评分 clone):逐房间 photo-evidence、可调权重模型、Verdict 卡导出闭环。

## 明确延后(非拒绝)
- 伴侣协同(先靠 Verdict 卡分享,实时协作 v2)。
- 看房提醒/日历集成(v1+)。
- 更多导出模板(compare PDF、房东问询清单)。
